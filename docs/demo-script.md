# 5-minute demo path (draft)
1. Student opens the app on a phone with Wi-Fi off; practice still works.
2. Gets a Kinematics question wrong; asks a doubt in Punjabi.
3. Tutor diagnoses the concept, gives a hint, student tries again, gets it.
4. Short timed mock test, then a mastery map showing the weak concept and next 3 items.
5. Teacher dashboard: class view, an at-risk student, override what they do next.
6. Review queue: an LLM explanation that failed verification is caught and never shown.
7. Close with numbers: verification pass/fail rate on the question bank.
