# BJF AI Coach (SARBAT Build Day)

AI-enabled JEE/NEET coaching for rural Punjab students, built for Bhai Jaitajee Foundation.
Scope for Build Day: one chapter (Class 11 Physics, Kinematics), done properly.

- `CLAUDE.md`: project context and rules for humans and coding agents. Read first.
- `docs/spec.md`: data schemas and API contract.
- `docs/demo-script.md`: the 5-minute demo path. If it isn't on this path, don't build it yet.
- `data/seed/`: sample questions in the agreed format.
- `content/verify/`: verification pipeline (answer-key checks).
- `backend/`, `app/`: API and student/teacher PWA.
